OBJECTIVE BEND: coroutine pseudocode, not a tested interpreter.
W(t) returns weak-head values. Nested calls propagate yields, retaining stack;
yield(p) hands raw p to host; a supplied response becomes its return value.
Capture-avoiding t[u/x]; fresh binders; left-associated application.
Values: \x.t, Nat, Bool, String, {fs}, spec(m,e), proto(s,t), inj(k,t).
W(v)=v: constructor children stay unevaluated; scalar types are disjoint.
W(f a): match W(f): \x.t=>W(t[a/x]); spec(m,e)=>W(e a)
W(mix(a,b))=\s.\p.b s (a s p)
W(fix(e,p))=W(e (fix(e,p)) p)
W(reflect(t)): proto(s,u)=W(t); return W(s)
W(metadata(t)): spec(m,e)=W(t); return W(m)
W(target(t)): proto(s,u)=W(t); return W(u)
W(t.k): {fs}=W(t); return W(first(fs,k))
W(extend(t,gs)): {fs}=W(t); return {gs++[f in fs | key(f) not in keys(gs)]}
W(if(c,a,b)): match W(c): true=>W(a); false=>W(b)
W(natcase(c,z,x.b)): match W(c): 0=>W(z); n+1=>W(b[n/x])
W(case(c,arms)): inj(k,u)=W(c); x.b=first(arms,k); return W(b[u/x])
W(done(t))=W(t); W(perform(p))=W(yield(p))
W(op(a,b)): v=W(a); w=W(b); return primitive(op,v,w)
Nat: +,*,-,/,%,=,<,<=; unbounded; subtraction saturates; floor division;
n/0=0; n%0=n. Bool: strict AND. String: equality. Other operands: stuck.
Fields/arms: ordered string-keyed lists; first match wins. Every missing
case/field or shape mismatch is stuck. Infinite recursion diverges.
Every layer shares final self s; p is the whole lower computation.
Host: object=(id,code-pin,versioned-state,law). Reference != authority.
An authenticated turn evaluates pinned code; effects commit atomically only
if exact read roots match and current law/authority admit all writes.
Pure computation grants no effects. Failed turns make no application writes.
Sponsorship/budget are host policy, not intrinsic object identity; principal
and authority remain semantic inputs. Failed turns may still incur charges.
Grants face current law; revision != revocation. No owner recovery bypass.
Delegation is explicit and scoped to callee, method, code and arguments.
Synchronous call trees commit together; sends enqueue durable messages and
return answer slots; delivery is a later turn. Slots have one decider,
a deadline and a terminal outcome. Resume consumes one checkpoint generation.
Success/refusal/unknown/timeout/breakage differ. No reply leaves outcome unknown:
query the signed request's receipt; retry same identity, lest action repeat.
Budget exhaustion != success. Privacy requires protected reads.
Typing fragment: exact finite row equality with rigid future Self/Super
bounds discharged at fix; fix:(C->V->C)->V->C, subject to shareability.
Affine/linear safety: use <=1; reusable closures capture only unrestricted shareable
values. Activities cannot inhabit shared arguments, fields or payloads.
Plans are variants over first-order data; responses are first-order data.
W is call-by-name; heap sharing needs separate representation adequacy.
Omitted: complete type rules, parser, codecs, signatures, tariff/budget rules.
