application. \x.t binds x; fields/arms are ordered string-keyed lists;
lookup is first match. Values v: \x.t,Nat,Bool,String,{fs},spec(m,e),
proto(s,t),inj(k,t); their components remain unevaluated.
(\x.b) a -> b[a/x]
mix(l,u) -> \s.\p.u s (l s p)
fix(e,p) -> e (fix(e,p)) p
spec(m,e) a -> e a
reflect(proto(s,t)) -> s
metadata(spec(m,e)) -> m
target(proto(s,t)) -> t
{fs}.k -> lookup(fs,k)
extend({fs},gs) -> {gs ++ filter(fs,key not in keys(gs))}
if(true,a,b) -> a; if(false,a,b) -> b
natcase(0,z,x.b) -> z; natcase(n+1,z,x.b) -> b[n/x]
case(inj(k,t),as) -> b[t/x] if lookup(as,k)=x.b
done(t) -> t
op(v,w) -> scalar result iff operand types match.
