# Capsules

One-screen references for a model with little context, each under 2,500 characters and checked against the code. They are reading material, not runtime inputs.

- [world.txt](world.txt): the doors and objects, how to act, the refusal classes.
- [spells.txt](spells.txt): the spell grammar as the host reads it, completion, `badSpell`.
- [object.txt](object.txt): how to write an object (message dialect), with one complete example.
- [protocol.txt](protocol.txt): the world's methods, their results, `changed`, receipts.
- [laws.txt](laws.txt): the law fragment, readings, the metarule, the Bend predicate, classes.
- [relations.txt](relations.txt): `Relation<T>`, keys, edits and which commute, order, queries.
- [skeleton.txt](skeleton.txt): the sum-Plan dialect, valid until the objects migration lands.
- [delvetalk.txt](delvetalk.txt), [algebra.txt](algebra.txt), [rewrite.txt](rewrite.txt), [machine.txt](machine.txt): language sketches from the previous tree, not checked against this one.

For current behavior, read [docs/INDEX.md](../docs/INDEX.md) and the source.
