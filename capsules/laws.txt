LAWS: text in the source or given at creation, one clause a line: law NAME "reading": EXPR. At most 16
clauses and 4,096 bytes; top-level fields only; all must admit.
EXPR: A implies B (loosest, right) | A or B | A and B | not A | (A) | ATOM.
ATOMS. REF == TERM: request.kind == 0. REF <= TERM: new.count <= 100; old.last + old.gap <= request.clock.
TERM in [INT,..]: request.kind in [0, 2]. REF == "TEXT" (subject, caller, pin, method, object):
request.method == "tend". TERM in new.F (a list): request.subject in new.parties. TERM in new.F.COL (a
relation's column): request.caller in new.members.who. TERM in "OBJECT".F.COL: another card's rows, at
the version the turn read (a root; unviewable holds nothing). monotone(ticks): old <= new.
writeOnce(closed): one change, away from 0/false/""/[]. appendOnly(log): the old list is a prefix.
unchanged(terms). insertOnly(marks): every old row kept (a row the limit dropped counts as kept).
COUNTS count(new.F) | count(old.F) [where COL == TERM]: count(new.lines where author == request.subject)
<= count(old.lines where author == request.subject) + 1.
changed(new.marks.who) by request.subject: every row the write touched has that column.
under "kind/lamp": that card's `law` field holds here as if written here (every made thing's law is
under its kind's, so the kind's owner amends one law for all).
REF: new.F | old.F (before the write; empty at creation) | request.subject | caller | height | turn |
pin | kind | method | clock (world minutes) | object (the written id) | a count. kind by name or number:
write 0 (the object's own method), reprogram 1, amend 2, proposed 3 (a write no method made). A missing
or mistyped value fails closed.
READING: a refusal by clause N carries reading and reason "refused N: <reading>"; under a kind's law the
kind's clause is named. delvetalk library laws / card: <id> prints them, following under.
METARULE: an amendment stands only if the new law admits an amendment by its own proposer. With no law
given: owner: request.kind == 0 or request.subject == "<creator>".
GUARD a field: request.subject == new.owner or (request.kind == 0 and unchanged(F)).
PREDICATE (optional second tier): def law(old: State, new: State, request: Abi.Request) -> Abi.Verdict,
pure, 100,000 ticks, after the text admits a kind-0 or 3 write. Request {context, method, argument: Data,
kind, pin, reads} (reads: the ids def lawReads() names). Verdict admitted {} | refused {clause, reading}.
CLASSES: transient, retry the same: staleRoot budget evaluation capacity quota quiet. Binding: lawRefused
typeMismatch absentItem unknownObject duplicateIdentity programRefused requiredAbsence budgetExhausted
keyTaken duplicateKey badSpell noMethod. Eighteen; no other.
