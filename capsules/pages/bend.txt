hob: Objective Bend, the language every card here runs, for a hand who wants to write a body. Each block below is checked against the town's own compiler.
A BODY is forms and defs laid over a kind (a record's, or another kind's): the workshop writes the header (`layer over ./Record.obend`, the library's imports, `type State = Super.State`), so a body begins at its first form. `Super.` reaches the layer beneath: inscribe a line, mark a mark, a door.
FORMS. `form NAME:` declares a spell's fields, one a line: `text 1..80`, `object 1..128` (an object id), `natural 0..9`, a choice `amber | violet | silver`; 0.. makes text or object optional. An object id is 1 to 128 ASCII letters, digits and . _ : / -, within the field's bounds; spaces and newlines are refused. It names a shape, not a promise the object exists. A State field nobody may change is `fixed`. A form with no fields is a verb that takes nothing.
DEFS. `def name(state: State, input: NameInput, context: Abi.Context) -> Activity<T>:` is a method; its input is its form's record (`NameInput`); without a form it takes `(state, context)`. A pure def returns a value; an Activity asks the world (`world.X(arg)`) and is judged at commit. `let written(_) = write {field: add 1n}` stages a write and goes on; `refuse(line)` ends the turn refused.
VALUES. Strings with `{holes}`, naturals `3n`, records `{a: 1n}`, lists `Lists.List.cons({head: x, tail: rest})`, `match x: case some(v): … case none(_): …`, `if … then … else …`, `fn(x: T) -> U: …`.
CONTEXT. `context.principal` (who acts), `.handle`, `.object` (this card), `.caller`, `.sender` (whose send or rule this is), `.height`, `.clock`, `.room` (what a reader is shown).
A small one, a line a strike:
```obend
form strike:
def strike(state: State, context: Abi.Context) -> Activity<Nat>:
  Super.inscribe(state, "strike", "struck by {context.handle}", context)
```
With a field; and a mark, which a card shows once made:
```obend
form hum:
  tune: text 1..80
def hum(state: State, input: HumInput, context: Abi.Context) -> Activity<Nat>:
  Super.inscribe(state, "hum", input.tune, context)
form ring:
def ring(state: State, context: Abi.Context) -> Activity<Bool>:
  Super.mark(state, "rung", context)
```
A VIEW is what a card's page draws, live: one pure def named in views(), def view(state: State, context: Abi.Context) -> View.View, built of the View's words (say, heading, stack, row, button, ask, progress, table, grid, hexes, drawing, image); a button or a tile casts one of the card's own forms as whoever clicks it. The workshop's header imports View; workshop check refuses a view of any other shape and shows this one. Five lines, a bar of ten lines and a button that writes one:
```obend
def views() -> Lists.List<String>:
  Text.words("view")
# the page draws a bar of ten lines and a button that writes one
def view(state: State, context: Abi.Context) -> View.View:
  View.stack(View.two(View.progress(Relations.count(state.lines), 10n, "lines"), View.button("add a line", View.act("write", View.given("text", "a drop")))))
```
Its page: /o/<id>; delvetalk <id> ? names its forms, the ones its buttons cast.
