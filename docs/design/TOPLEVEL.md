# The living conversational document

The top level is a governed source encounter. Its document presents prose,
offered actions, fields, references, source, results and continuations around one
retained intention. Literal contributions, interpreted utterances and source-cell
records use that same source state and authenticated caller. Presentation grants
no authority; native preparation and admission retain exact roots and apply
current law.

## One continuing intention

[Conversation](../../protocols/conversation/README.md) retains the selected offer,
partial bindings, unanswered questions, attributed contributions and outcomes.
The account notebook’s `note` takes one thought; its `record` accepts source and
result text. Supplied result text is a record, rather than proof that code ran.
The lending Notebook validates its configured offered references and fields.
Completing it invokes the separately governed object, then consumes the actual
result with authenticated origin. A copied result cannot complete the intention.

A document offer carries authored meaning metadata. It resolves against an actual
captured invitation; its label, token and revision are not a native program pin or
a reusable grant. Fields preserve incomplete answers, and source decides which
question remains. A stale capture refuses rather than selecting a different
offer. Exact retry recovers the original attempt before a new contribution.

## Templates are ordinary source

[Document](../../world/lib/document/Document.obend) defines text, sequence, quote,
reference, offer, fields, source, result and continuation nodes.
[Templates](../../world/lib/document/templates/README.md) use `doc"""..."""`:
`{{ expression }}` inserts String text and `{% expression %}` inserts a Document.
The compiler lowers both to calls through the explicitly imported module, retains
original source and maps diagnostics to it. Text cannot manufacture an offer.

Ordinary Bend functions, imports, conditionals, matches and recursive collections
provide partials and iteration. Function-valued slots and `self`/`super` extensions
specialize reusable sections. Template rendering receives explicit already
acquired data. It neither reads an ambient world nor invokes a model. Editing a
stored string does not create another template evaluator; changing template
behavior uses exact source revision and governed adoption.

## Interpretation is an explicit activity

[Source interpretation](../../protocols/interpretation/README.md) owns prompt
construction, vocabulary, examples, escalation and permitted context. The
Notebook exposes its stored policy through the offered “Prompt and conventions”
edit. Source chooses the current fields, recent contributions and actual offered
references supplied to a provider; a prompt receives no automatic private archive.

A model request retains original content, policy revision, selected capture and
explicit context. The physical adapter performs bounded provider I/O and retains
its result. Source checks the reply and prepares an ordinary typed contribution;
receiving derives the actor from authenticated context and rechecks policy and
capture. A model result grants no permission to execute the proposed domain action.
Literal fields work without a provider. Refresh renders retained values rather
than spending another model call; exact retry reuses the retained activity.
