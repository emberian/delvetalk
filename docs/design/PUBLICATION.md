# Source-owned publication projections

An authenticated private read grants access to the private encounter. It does
not grant permission to use that material as a public Town draft.

Town requests the installed Bend view through native `opaque-view` with an
explicit `audience: "public"`, a selected panel, and the actual custody principal.
The receiving path requires the current law's exact panel grant to be the public
string alternative. A principal ACL (including a principal spelled `public`) is
not that alternative. Private read authority and a missing panel grant cannot
satisfy this request. Source `view` chooses the exported content; Town does not
filter arbitrary captured state into a public presentation.

The returned projection carries the exact retained-root reference, panel and
public audience. Public cards retain only that projection, its source-authored
form schemas, and bounded opaque invitation selections. They carry no private
root, state, law, source package, or caller-visible transaction plan. Source
`actions.fields` can expose editable forms alongside fixed `input` arguments.
Public source invitations select their preparation exports and declared
observations in Lean; their exact retained observation references survive custody
and retry. The transport supplies contributions and authenticated identities.

Ordinary forms submit `opaque-invoke` with the original exact reference. Source
invitations submit the original selection and contribution through
`opaque-transaction`; admission reruns the same bounded pure source preparation
privately under current authority. The public view grant grants neither invocation
nor dependency reads. Current method authority and exact preimages still govern
admission. Revocation or source/state drift refuses a new turn. Retained terminal
receipts recover the original projected reply without replaying that turn.

Town's public response body uses a generic turn acknowledgement and a fresh
source-selected public projection. Arbitrary private invocation results,
refusal diagnostics, interpretation notes and full roots remain local custody.
Retrieving a saved public draft or binding it to an already-existing verified
post rechecks its exact current root and audience using the same native view
query. An unavailable draft does not erase its original receipt. Publication
remains paused; these APIs never send or publish a post.

The focused native fixture is `conformance/test_publication_projection.py`.
It separates an owner-only secret panel from an explicit public count/form,
checks edited input through the actual receiving path, refuses stale references
and audience withdrawal, and recovers the identical terminal receipt after
revocation. Source source checks and native receiving qualification are distinct.

The source view boundary accepts additional bounded package-data fields without
a host field whitelist. The native schema check rejects executable values;
physical renderers consume known presentation data without granting authority.

All source form clients frame bounded inert contributions through the shared
physical helper. Field hints describe forms; Python does not enforce their
minimum, maximum, enum choices, or permitted contribution names. Native source
preparation chooses questions, refusals and effects. Typed native methods still
check direct invocation inputs. Literal form text decodes declared numeric and
Boolean fields without interpreting hints as authority.
