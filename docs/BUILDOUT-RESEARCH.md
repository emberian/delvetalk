# Build a world its inhabitants can change

**The useful unit is a complete loop:** enter → act → inspect source → propose/check → adopt under current authority → use → replay. More rooms do not substitute for this loop. The local implementation now connects it; [BUILDOUT](../BUILDOUT.md) records evidence, [LIVE-BOOTSTRAP](LIVE-BOOTSTRAP.md) separates launch obligations.

## Mechanisms worth keeping

| Primary precedent | Mechanism → design choice |
| --- | --- |
| [Self/Morphic, Maloney–Smith (1995)](https://bibliography.selflanguage.org/directness.html) | Inspectable components → one object identity with source/actions/history views. |
| [Lively Kernel, original account](https://lively-kernel.org/repository/lively-kernel/trunk/doc/website-index.html) | Environment tools implemented within the environment → version ordinary construction tools; identify the trusted bootstrap. |
| [Webstrates (2015), pp. 3–5](https://www.klokmose.net/clemens/wp-content/uploads/2015/08/webstrates.pdf) | Shared substrate, personal instruments → shared program/state; private layout/drafts. Transclusion must preserve identity, not clone custody. Script updates requiring reload do not establish arbitrary hot replacement. |
| [LambdaMOO manual, §2.2.3](https://www.wrog.net/moo/pm1.8.3/ProgrammersManual.pdf) | Discoverable programmable verbs → readable object actions; separate play, programming and law authority rather than inheriting a powerful author's identity. |
| [Miller, Robust Composition (2006), ch. 21](https://erights.org/talks/thesis/markm-thesis.pdf) | Designation with least authority → explicit object/action grants. Copying code or a reference does not copy permission. |

These are design inferences from inspected primary sources, not transferred security guarantees. [PORTAL-PRECEDENTS](PORTAL-PRECEDENTS.md) extends the interaction vocabulary.

## Three connected instruments

**Room/source desk.** Show committed state and its matching source. Proposals retain source/compiler identity, checked artifact, expected root and explicit migration. Compilation cannot install. Numeric passage indices cannot survive reordered source without a deliberate mapping or restart. [Desk](../profiles/DESK.md), [room](../scene/ROOM.md).

**Versioned tool.** Separate reusable program from current grants. [Scoped laws](../profiles/AUTHORITY.md) distinguish commands, programming and law revision; they do not implement transferable capabilities. Every transaction callee checks authority; exact retries retain historical outcomes.

**Two-player table.** Use the actual pinned compiled game, hide moves until both commitments, preserve rules during play, and replay complete admissions. Missing players require a separate liveness policy. [Table](../game/table/README.md), [history](../profiles/HISTORY.md).

## Userspace direction

The pure contract is `view(programRevision, committedState, panel) → ViewData`: prose, references, actions and provenance, without ambient host code. [VIEW](../profiles/VIEW.md) executes installed Bend projections through Lean. Renderers prepare exact-root requests; admission remains separate. Parsing, lowering, custody and trusted installation remain explicit bootstrap components. Replacing one real computation and its consumers advances self-hosting; renaming adapters does not.
