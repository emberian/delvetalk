# The workshop runs; public inspection and receiving are separate

**The café, source desk, programmable sign and two-player table are implemented local paths.** Earlier missing-component proposals are superseded by [BUILDOUT](../BUILDOUT.md), [README](../README.md) and their linked profiles. No new public receiving deployment follows from those results.

```sh
python3 scripts/bootstrap.py run /tmp/my-delvetalk-cafe --profile compiled
python3 scripts/bootstrap.py view /tmp/my-delvetalk-cafe --html > /tmp/cafe.html
python3 scripts/bootstrap.py table /tmp/my-delvetalk-cafe
```

Use a new directory and prebuilt dependencies. [Bootstrap source](../scripts/bootstrap.py) joins shared repairs, source-bound views, proposal checking, atomic adoption and changed behavior. Rendering reads committed state without replaying entry effects. Saved choices retain exact roots. Migrations supply explicit replacement state; reordered passages cannot inherit numeric indices blindly.

[Scoped law](../profiles/AUTHORITY.md) separates play, programming and management. Compiler grants do not install; [desk adoption](../profiles/DESK.md) and target replacement commit together. A desk's release alone does not establish installation. Local principal strings are assertions, not authenticated identities.

The [table](../game/table/README.md) runs Mini's actual compiled package and demand engine. All 353 historical Bend results match; ten documented Rust differences remain. Commitments bind domain, receiver, round, seat, move and nonce. Both commitments precede reveal; conflict/invalid pairs advance the commitment round. Rules are pinned by the installed protocol and absent management grants. There is no timeout winner or forced reveal. Do not publish private openings early, even in requests expected to refuse.

[History](../profiles/HISTORY.md) reconstructs ordered admissions, artifacts and atomic edits using trusted anchors and a trusted local engine. Exact-runtime replay is default; source-matched replay is explicit. Neither proves compiler adequacy, public authorship or consensus. The [worker](../profiles/WORKER.md) prepares publication locally; an outbox is not delivery.

## Public launch contract

The [powerbox proposal](https://delve.town/profile/ember.delve.town/post/3mxen3fdeo224) names an imaginary textual address, not an account or notification dependency. The [canon objective](https://delve.town/profile/ember.delve.town/post/3mxeluynis22j) requires public reconstruction.

Launch needs a real entry/receipt route, receiving cadence, exact runtime/source/authority profiles, restart reconciliation and publicly verifiable ordered history with one identity per multiobject commit. Another participant must enter, change the place and use the result; a third must reconstruct it after restart.

The [kernel capsule](../capsules/rewrite-2k.txt), identified by [manifest](../capsules/manifest.json), excludes full typing/admission/encoding. Pair it with those profiles. Local reprogramming does not establish a self-hosted compiler; runtime changes require an explicit epoch and migration.
