## Cycle 1 ownership and joins

- **Authority:** `WorldCore.lean`, `Transactions.lean`, authority profile/tests.
  Preserve legacy laws. New exact scoped law separates named-command invocation,
  reprogramming and law revision; every callee checks current law in Lean.
- **Package engine/game:** byte-exact Mini frontend and demand modules, generic
  package adapter, pinned two-player Automatafl qualification. Root owns source
  manifests and build configuration. No game rules in Python.
- **Room:** committed-state rendering joined to exact source artifacts, a repair
  café scene, machine and human views. Never replay entry effects while rendering.
- **Source desk:** ordinary candidate objects, compilation artifacts/diagnostics,
  and explicit adoption. Compiler authority never implies installation authority.
- **History:** trusted-genesis/head replay using the actual admitted requests and
  engine; one commit covers a multiobject interaction. Hashes do not authenticate
  a custodian, and omitted source/runtime artifacts must remain explicit.
- **Worker:** bounded discovery, receiving, recovery and publication preparation.
  Incoming prose is observation; only explicit supported requests enter admission.
- **Research:** a few source-grounded affordances that improve the inhabitable
  environment without adding redundant subsystems.
- **Independent review:** privilege, source/version and recovery counterexamples
  across the joins, with fixes coordinated through the owning lane.

Two local Lean compiler seats: authority and package engine. Other lanes use
built binaries and request builds through their owners. Root owns shared Git,
build/test integration, source provenance, and final composed acceptance.

## Interface decisions

`delvetalk-scoped-law-v1` is an exact object with `profile`, `invoke` (command
names to principal arrays), `reprogram` and `law` arrays. Missing command means
deny. No implicit owner, wildcard, or recovery bypass. Read access remains public
in this named bootstrap profile. Pure programmable policy further restricts those grants under the common
evaluation budget; it cannot grant authority absent from the scoped law.

Transaction reprogramming shares current-law checks, exact initial read roots,
one outcome and rollback with ordinary calls. The source-desk adoption join
passes an earlier candidate call's exact `{protocol,state}` result into a later
reprogram call; Python does not decide whether two candidates are equivalent.
Releasing a candidate by itself is not evidence that a target installed it.

Public reconstruction and endogenous programming remain completion criteria.
A successful local fixture does not establish a public receiving deployment.
The bootstrap must expose exact programs and their history to participants,
retain uncertain outcomes, and let another participant use an admitted extension.
