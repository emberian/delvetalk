# An evening built together

Moss makes a scheduled bell. Iris makes a door and lantern. The shared courtyard
book retains their attributed conversation and links to their creations. Each
linked object keeps its own state and law; following a link requires a current
receiving read. The book does not retain copies of its neighbours' state.

The executable receiving journey is `conformance/test_evening_courtyard.py`:

```sh
python3 conformance/test_evening_courtyard.py
```

Run it against a qualified compiled host matching the checked source closure.
The test does not build native compilers. It uses source ObjectFactory invitations
to allocate the three objects, Iris's observed recipient binding, Moss's source
appointment preparation, a retained physical clock observation and durable causal
message delivery. It checks exact retry, relay restart, stale observed roots and
refusal of Moss's attempted change to Iris's door.

`CourtyardBook.obend` owns the conversational document. `AfterglowBook.obend` is
an authored presentation revision. The revision test retains and checks its exact
module proposal in an ordinary source Candidate desk, then lets the courtyard
steward accept it through the source release invitation. Moss and Iris cannot
install that shared revision. Acceptance preserves the existing conversation,
references and current law. `book.examples` supplies the authored note examples
for the proposal's native check.

`package.py` only loads exact source and configuration through the native source
constructor. Physical test orchestration is in Python; object behavior, preparation,
allocation, causal reactions and proposal release are authored in Bend.
