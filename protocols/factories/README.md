# Ordinary source factories

`Object.obend` owns the editable object's state, text bound, decisions and view.
`Factory.obend` owns allocation, participant selection, child law and the visible
make invitation. `Creation.obend` is the shared source preparation operation:
retain the factory root, declare the exact child absence, then invoke make.
`package.py` carries these ordered modules and evaluates their source constructors;
it does not generate methods or permissions.

The compiled receiving host admits these objects. A factory permits at most 16
current direct children. The actual maker and configured participants receive the
child's flat law. A raw write over 512 characters is refused by the source method.
Management of the factory changes future children; it grants no implicit authority
on already allocated children. Current authority, exact absence, collisions and
retry receipts remain native receiving decisions.

The workshop seed uses these packages and the separate source Candidate factory
in `../source-desk`. A make invitation captures the object and declared absence;
its source preparation constructs the request. It does not refresh a retained
root. `object.examples` contains source-object use examples. The general kernel
allocation fixtures live under `conformance/fixtures`, outside the production seed.
