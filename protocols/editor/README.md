# Repeated authored editing

`Editor.obend` owns the workshop's behavior and preparation. Its ordinary
`initial(config)` constructor takes explicit target and factory identities;
`generate.editor_artifact` loads that source and runs the checked constructor.
Configuration does not rewrite source. Grant the five receiving methods
explicitly; the factory independently grants allocation, and the target's
current law governs reprogramming.

The normal encounter offers four invitations. `prepareMake`, `prepareSubmit`,
`prepareReview`, and `prepareAdopt` receive contributions and captured
observations and return a complete turn, an authored question, or a refusal.
They construct actual calls in Bend. No client interprets aliases, substitution
paths, call slots, or a separate workflow language.

Making a variation allocates a fresh immutable candidate and captures the
target baseline. Submission carries exact source and examples plus the captured
target state. The explicit compiler queue completes that candidate. Authentic
reports select only the current generation; older jobs cannot make a newer
variation ready. Adoption checks the current target baseline and authority,
then immediately consumes the native reprogram result. `finish` checks its
origin, target, version, and exact program digest before recording adoption.
A changed target asks for a fresh variation to rebase. Earlier pending, failed,
ready, and adopted generations remain retained; the factory quota is 32.

Town and Portal discover the same source invitations in the ordinary encounter.
Their capture retains the owner and declared observations. Preparation never
refreshes them or touches world custody. Questions and refusals are retained
separately from executable turns. `scripts/editor.py` only retains the native
preparation and exact admission receipt, recovering the same request after an
uncertain reply. Publication remains separate.

Source text is bounded to 32 KiB and examples to 16 KiB. External contributions
remain bounded to 64 KiB; expanded native transactions, including exact roots,
are bounded to 1 MiB. Captured observations grant no authority. The receiving
native transaction checks exact preimages, absences, current laws, and authentic
prior-result provenance.

`Counter.obend` and its examples supply a small editable instrument.
`conformance/test_editor_generations.py` covers overlapping generations, a late
job, failed compilation, target drift, rebase, adoption, lost-reply retry, exact
restoration, and another revision. `test_preparation.py` and
`test_town_preparation.py` exercise the native preparation boundary and ordinary
post encounter independently. These are local examples, with no publication or
remote authorship claim.
