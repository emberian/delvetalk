# DelveTalk construction record

## Working paths

- Four independent Lean/Python/JavaScript/C core evaluators; positive Lean
  classifications carry proofs against the pinned Mini source relation.
- Eleven byte-counted capsules. Reconstruction experiments live separately in
  `experiments/`; they neither define correctness nor gate implementation CI.
- Lean protocol admission with exact roots, current law, atomic state/results/
  outbox, retained success/refusal receipts and bounded pure Bend computations.
- Ordered multiobject transactions reuse the same evaluator and receipts, with
  one budget and atomic rollback; earlier results can feed later calls.
- Governed reprogramming replaces protocol and explicit state under current law
  and exact preimage. Both local management and repository-authored requests
  reach the same Lean operation; historical receipts survive program changes.
- A separate annotated typed-core interface runs Mini's pinned checker, including
  rigid bounds and quantity/capture checks. It does not grant host authority.
- The shared workshop connects typed computation, proposals, transactions,
  answer slots, concurrent completion and governed program replacement in one
  runnable interaction between scripted local participants.
- Source-preserving versioned syntax adapters, isolated proposal checks and
  public-post intake. New dialects require reviewed translators and validators.
- Pinned actual Spween parser/runtime and executable i64 scene lowering, checked
  against the upstream runtime. Float source is preserved but not executable.
- Explicit PDS clerk, repository-derived principals, compact social requests,
  exact published-root references, immutable receipts and CAS root publication.
- Explicit quiescent custody upgrades preserve world bytes and historical
  receipts; operator management separates repository enrollment from current law.

## Outstanding implementation work

- Operator-run clerk processing is not an unattended receiving service. Add a
  supervised queue only with an explicit deployment/operating policy, delivery
  bounds and operating policy. Enrollment and law management are implemented;
  remote requests cannot install new law.
- PDS identity assurance trusts one named HTTPS custodian. Independent DID/CAR/MST
  verification and federation are not implemented.
- Quiescent upgrades refuse pending work. Concurrent runtime versions and routing
  pending attempts to their original executables remain unimplemented.
- Outbox entries need specific effect adapters and reconciliation contracts.
  Existing receipt publication is not exactly-once external effect delivery.
- Local reduction fuel does not bound every host memory/arithmetic cost. A public
  receiver needs process/resource isolation in addition to semantic admission.
- Complete core inspection, parser/runner refinement and compiler equivalence
  remain proof obligations; fixture agreement is scoped executable evidence.
- Spween floats, arbitrary stateful external handlers and transactional comparison
  with upstream error paths need separate explicit profiles.
- Two-player Automatafl remains the separately pinned Mini example. Preserve its
  documented implementation differences; do not add unstable n-player variants.

## Latest resolved boundaries

Audits found and fixed zero-fuel C contraction overflow, Python's decimal integer
conversion ceiling, timestamp-tie/clock-rollback posting checks, malformed scene
initial-state normalization, and feed posts requiring TID record keys. Regression
suites exercise each. Live evidence belongs in `evidence/`; account credentials,
private prepared records and local world databases remain outside the repository.
