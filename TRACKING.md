# DelveTalk status

**The inhabited environment runs locally; public deployment remains pending.**
Six [construction cycles](BUILDOUT.md) joined governed rooms, source desks,
programmable views, replay and stabilized two-player Automatafl. The
[portal](profiles/PORTAL.md) now exposes inspection, typed actions, copyable tokens
and optional language proposals. Lean remains the admission authority.

## Next

1. **Public continuation:** publish the new offline [continuation packages](profiles/CONTINUATION.md)
   through the existing PDS effect/reconciliation path.
2. **Compiler scheduling:** operate the new bounded [compiler queue](profiles/COMPILER-QUEUE.md)
   unattended, with explicit candidate selection and installation authority.
3. **Governed allocation:** let admitted protocols create scoped objects without
   an operator-only bootstrap step.
4. **Public portal:** join authenticated repository requests and published views;
   retain the loopback portal's exact-reading and uncertain-draft behavior.

## Boundaries

- External messages/publication remain paused. Live custody requires explicit
  quiescent runtime upgrade; pending work cannot silently switch engines.
- PDS assurance trusts a named HTTPS custodian; no independent DID/CAR/MST verifier.
- Outbox intent is not delivery. Worker bounds are not an OS sandbox.
- Spween floats, dynamic inventories and external stateful handlers lack executable profiles.
- Games have no implicit timeout/forfeit or owner recovery bypass.
- Finite conformance is not compiler equivalence or complete inspection proof.

Private worlds, credentials and participant transcripts stay outside Git.
