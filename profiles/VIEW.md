# Source views

Installed Bend views project a captured state without mutating the world. Native
source evaluation checks the view’s schema and bounded materialized result.
[Projection](../scene/projection.py) retains the exact owning source package,
state, selected panel and runtime identity. Capture first acquires governed reads
under the authenticated reader; a denied read cannot become a rendered card.

`view(state,panel)` returns title, prose, offered actions and children. Source
views may additionally offer documents, preparation invitations and interpretation
through checked shared contracts. All descriptors are validated before visibility
filtering. Hidden actions still face current law on direct invocation; visibility
is not authority.

Actions can use a fixed typed row or an ordered source collection of descriptors
with distinct typed inputs. Keys must be unique and bounded. Children are a
bounded typed collection carrying key, label, object and panel. Following a child
captures a fresh observation under that child’s current read law. A reference
grants no authority, enrollment or implicit fetch.

Invitations select an actual preparation export and exact requested observations.
Answers supply contribution data; they cannot replace the captured export,
package or observations. Source preparation returns a question, refusal or proposed
turn. Native admission separately checks current law, exact roots and effects.
See [preparation](PREPARATION.md) and [source objects](TYPED-SOURCE-OBJECTS.md).

The current captured-card routes share offered meaning. Result-only public
invitation routes remain under construction and require matching receiving
qualification. Retained cards bind the exact
reading and native/source identity. Another actor’s change makes the old action
stale. After an uncertain reply, recover the original attempt before preparing
another one. Panels and copied cards grant no authority.

A failed source view may leave a technical inspection of permitted source/state;
it offers no fabricated actions or children. Child navigation reports the failed
view as unavailable. HTML escapes data and restricts scripts and remote resources.
View work, input and output have native/physical bounds; overflow refuses rather
than truncating a menu.

[View action checks](../conformance/test_view_action_lists.py),
[typed projection checks](../conformance/test_typed_view.py), and
[child navigation](../conformance/test_child_navigation.py) exercise the matching
native/source path. Passing local cases does not establish deployment.
