How it is built

Three rules hold everywhere. Plans are the only effect language. Python carries bytes and decides nothing. Every journal entry is a record.

A turn

def bump(state: State, context: Abi.Context) -> Activity<Plan, Response, Nat>:
  let written(_) = perform(write {count: add 1n})
  state.count + 1n

A method is an activity. It yields Plans (view, write, call, send, create, await, interpret, reprogram, amend, grant and twenty more); the host answers each from the store and records every root read. At the end the turn commits only if every root is current and every written object’s law admits the write. A suspended turn is a checkpoint in the store and survives restart.

Law

One line per clause, printed on the card: law owner "only the owner changes it": request.subject == new.owner. A law is accepted only if it admits an amendment by its own proposer, so no law can seal out the hand that wrote it. An optional pure Bend predicate law(old, new, request) refines it under a fixed budget.

Not adopted: linear types at the affordance level, relational laws by a solver, Datalog over the journal. Capabilities are journaled grants the host checks, not kernel values; the confused deputy is answered by via, never by impersonation.
